2. IAI (правило в `.cursor/rules/iai.mdc`) розбирає бриф → `specs/01-brain.md`.
3. Пишемо спеки: концепція, структура, візуал, рух, платформа.
4. Чистимо голос (без канцеляриту й AI-формул).
5. Збираємо сайт уже по спеках.

Поки брифу немає — не вигадуємо бренд, офер і сторінки.
