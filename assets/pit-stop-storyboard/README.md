# Pit-stop storyboard panels

Six storyboard illustrations for the "How we work" pit-stop flow
(PR #13 — "Rewrite site copy and turn How we work into a pit-stop flow").

Each image is one station (gear) of the F1 pit-stop metaphor. Together they form
one connected storyline: the client's project rolls in as the "car", passes each
station — with red/green gates where a signature is required — and leaves as a
finished, installed interior.

| File | Step | `steps` key | Gate |
| --- | --- | --- | --- |
| `step-1-analysis.png` | Analysis — study drawings, specs and measurements, then estimate | `consult` | — |
| `step-2-engineering.png` | Engineering — production drawings and samples | `design` | — |
| `step-3-contract.png` | Contract — scope, price, schedule signed | `confirm` | Approved for Production |
| `step-4-production.png` | Production — cutting, CNC, veneer, assembly, finishing, QC | `manufacture` | QC Approved |
| `step-5-delivery.png` | Delivery — labelled crates by sea, road or air | `deliver` | Approved for Shipment |
| `step-6-installation.png` | Installation — install and handover, warranty starts | `support` | — |

Style: black-and-white pencil/marker sketch with red accents and DSGN CHOICE
branding, matching the original client storyboard. Captions are in Russian (uppercase).

These are source assets only; they are not yet wired into the site UI.
